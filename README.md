# dossier-css

Shared dossier stylesheet for Noodle Factory technical artifacts.

## CDN

Pinned jsDelivr URL:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/noodle-factory/dossier-css@v2.0.0/dossier.css">
```

Use pinned tags in generated artifacts so existing documents stay stable when the stylesheet changes.

## Source

`dossier.css` is the sidebar-nav technical reference style used by `nf-artifact`: IBM Plex Mono headings, IBM Plex Sans body text, sage paper, teal accent, categorical badges, risk callouts, dark code blocks, responsive tables, and Mermaid-friendly diagram wrappers.
